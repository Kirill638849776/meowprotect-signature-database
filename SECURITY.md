# Политика безопасности

Спасибо, что помогаете делать MeowProtect безопаснее. Этот документ описывает,
как сообщать об уязвимостях и как мы обрабатываем потенциально опасные файлы.

## Поддерживаемые версии

| Компонент | Поддерживается |
| --------- | -------------- |
| База сигнатур (`signatures/`) | ✅ текущая |
| CI / GitHub Actions | ✅ текущая |
| Устаревшие форматы сигнатур | ❌ |

## Как сообщить об уязвимости

**Пожалуйста, не создавайте публичный Issue для сообщений об уязвимостях.**

Используйте один из приватных каналов:

1. **GitHub Private vulnerability reporting** (рекомендуется):
   вкладка **Security** → **Advisories** → **Report a vulnerability**

В сообщении укажите:
- затронутый компонент (CI, формат сигнатур, обработка файлов и т.п.);
- версию/коммит;
- шаги воспроизведения;
- оценку влияния.

Мы постараемся ответить в течение **72 часов** и сообщим о ходе исправления.

## Что считается уязвимостью

- Обход проверки файлов в CI (в т.ч. подмена результата «чистый/вредоносный»).
- Возможность выполнить произвольный код в GitHub Actions через присланный `.exe`
  или манифест.
- Утечка конфиденциальных данных из загруженных файлов или логов CI.
- Подмена/отравление базы сигнатур (`signatures/`) без прохождения проверки.
- Ложные срабатывания, которые можно использовать для блокировки легитимного ПО.
- Проблемы в самом формате сигнатур (например, возможность внедрить правило,
  которое отключит защиту).

## Правила отправки файлов (важно)

Проект принимает исполняемые файлы через pull request, поэтому:

- **Не загружайте файлы, содержащие персональные данные, ключи, токены,
  пароли или иную конфиденциальную информацию.** Даже после удаления коммита
  файл остаётся в истории git.
- **Не загружайте файлы, которые вы не имеете права распространять.**
- Загружая файл, вы подтверждаете, что он может быть проанализирован и,
  при необходимости, опубликован в базе сигнатур.
- Мы оставляем за собой право отклонить или удалить любой PR без объяснения причин.
- Файлы могут передаваться во внешние песочницы/анализаторы; не загружайте
  то, что не должно покидать ваш контроль.

## Как мы обрабатываем потенциально опасные файлы

- Файлы анализируются в изолированной среде; мы не запускаем их на
  инфраструктуре, где хранятся секреты.
- Мы не гарантируем обнаружение всего вредоносного ПО. **MeowProtect не является
  заменой Защитнику Windows или другому полноценному антивирусу.**
- При обнаружении вредоносного образца мы фиксируем сигнатуру и можем
  опубликовать её; сам образец может быть удалён из репозитория.
- О ложных срабатываниях сообщайте через Issue с меткой `false-positive`.

## Ограничения и честные оговорки

- Проект находится в ранней стадии; база сигнатур и процесс проверки могут
  меняться.
- Мы не храним личные данные пользователей намеренно, но **не можем гарантировать**,
  что присланный файл их не содержит — ответственность за это несёт отправитель.
- Публикация сигнатур не означает, что они немедленно применяются всеми
  потребителями базы.

## Безопасность аккаунтов и CI

- Секреты CI хранятся в GitHub Secrets и не выводятся в логи.
- Доступ к настройкам репозитория и workflows ограничен мейнтейнерами.
- Подозрительные PR (спам, дубликаты, файлы с признаками вредоносного кода)
  могут быть закрыты без рассмотрения.

## Контакты

- Уязвимости: приватный канал выше.
- Ложные срабатывания и вопросы: публичный Issue.
- Нарушения кодекса поведения: см. `CODE_OF_CONDUCT.md`.

Спасибо, что ответственно относитесь к безопасности. 🐾

# Code of Conduct

## Наше обязательство

Мы стремимся сделать сообщество MeowProtect Signature Database открытым, безопасным и дружелюбным местом для всех участников.

Мы приветствуем вклад от людей с разным уровнем опыта и ожидаем уважительного отношения во всех обсуждениях, issues, pull request и других формах взаимодействия.

## Допустимое поведение

Участники должны:

- уважать других участников проекта;
- предоставлять конструктивную обратную связь;
- помогать создавать безопасную и профессиональную среду;
- ответственно относиться к отправляемым материалам и предложениям.

## Недопустимое поведение

Не допускаются:

- оскорбления, угрозы и преследование участников;
- дискриминация по любым признакам;
- публикация вредоносного или намеренно опасного содержимого без соответствующего контекста;
- попытки нарушить работу проекта или сообщества.

## Ответственные сообщения

При обнаружении проблем с поведением участников или нарушений правил сообщества рекомендуется создать Issue или связаться с владельцем репозитория.

## Применение правил

Владелец проекта и поддерживающие участники могут принимать меры при нарушении данного кодекса поведения, включая удаление контента, закрытие обсуждений или ограничение участия.

Спасибо всем, кто помогает развивать MeowProtect Signature Database и делает проект лучше.
